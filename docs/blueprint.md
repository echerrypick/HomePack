# **App Name**: HomePack

## Core Features:

- Property Data Fetch: Fetch property data from Land Registry, EPC, Environment Agency flood monitoring, and planning.data.gov.uk based on UK address and postcode.
- AI-Enhanced Summary: Generate a summary of the fetched property data using AI, offering insights into key property features and potential issues using a tool.
- PDF Report Generation: Generate a downloadable PDF "Property Info Pack" containing the fetched data and AI-enhanced summary.
- Image Upload: Accept user-uploaded photos of the property.
- AI Condition Report: Generate an AI-powered condition report based on uploaded images, identifying potential issues with a tool.
- Address Validation: Provide address validation using postcode to give user choices.

## Style Guidelines:

- Primary color: Deep teal (#008080) for trustworthiness and sophistication, echoing the existing branding in the example images.
- Background color: Light grayish-blue (#F0F8FF) for a clean, modern feel. This matches the provided design example.
- Accent color: Teal-leaning cyan (#40E0D0) for CTAs and interactive elements, to draw the user's eye.
- Body and headline font: 'Inter' for a clean and modern user experience, providing good readability for report data.
- Use clear, simple icons to represent data categories (e.g., Land Registry, EPC) within the Property Info Pack.
- A clean, modular layout with clear sections for each data source and the AI summary.
- Subtle animations during data fetching and report generation to provide user feedback.
